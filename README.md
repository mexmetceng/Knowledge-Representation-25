# Knowledge Representation Group 25 (2026–2027)

A Smart Restaurant Menu Knowledge Base built using **OWL and Datalog** to represent dishes, ingredients, allergens, and dietary requirements.

The project explores logical reasoning to classify menu items, identify allergens, and determine dietary suitability while comparing two knowledge representation formalisms.

## 🎯 Project Objectives

- Develop a structured restaurant menu ontology using OWL.
- Implement logical rules using Datalog.
- Classify dishes based on ingredients and dietary requirements.
- Identify allergens through logical reasoning.
- Explore vegetarian, vegan, halal, and kosher menu classifications.
- Compare the expressiveness and reasoning capabilities of OWL and Datalog.

## 🛠 Technologies

- **OWL** – Ontology modeling and semantic reasoning
